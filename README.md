# NodeFX

Node-based program to procedurally generate textures for VFX.

## Download
**[⬇ Download the latest version](https://github.com/kfitzvfx/NodeFX/releases/latest)** → under **Assets**, click `NodeFX-Setup-x.y.z.exe`.

1. Run the installer. It installs in a few seconds, no admin needed.
2. If Windows says "Windows protected your PC", click **More info → Run anyway** (test builds aren't signed yet).
3. NodeFX updates itself: when a new version is out, it downloads it in the background and asks to restart.

Requires 64-bit Windows 10/11.
